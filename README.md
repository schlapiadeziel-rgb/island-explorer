# 潮汐之间 · 海岛探索

一个单页、原生 HTML/CSS/JavaScript 的俯视角海岛探索原型。无需安装，也不依赖第三方素材或运行时服务；地图与角色由 Canvas 程序化绘制。

## 玩法

在三处区域间航行、采集浮木、旧贝壳与潮光，协助雾灯港修复灯塔。修复需要 **3 根浮木和 2 枚旧贝壳**。灯塔点亮后，选择公开安全航路或交给海商公会：前者让岛民获得通行权并得到 2 枚旧贝壳；后者让贸易增长但航路受公会管制，并得到 2 根浮木和 1 枚潮光。两种结局都可继续探索。

## 键位与触屏

- 桌面：`W A S D` 或方向键移动；`E` 互动；点击底部区域按钮切换岛屿。
- 触屏：使用画面左下方向键移动，按“互动”收集或与人物交谈；点击底部区域按钮航行。
- 靠近物品或 NPC 后互动。页面无外部图片、字体、脚本或其他第三方素材依赖。

## 区域、势力与任务

| 区域 | 势力 / 人物 | 任务 |
| --- | --- | --- |
| 雾港群岛 · 雾灯港 | 港务自治会；灯塔守望者梅 | 收集灯塔修复材料，点亮灯塔后决定安全航路由岛民共享还是交由海商公会管制。 |
| 红脊雨林岛 | 巡林团；红脊矿业营地 | 调查矿业营地排污渠，收集污染水样并交给巡林团；证据提交后获得 1 枚潮光。 |
| 沉船礁 | 漂泊者聚落 | 风暴前取回沉船导航核心；归还聚落可得 2 枚旧贝壳，或留作装备改装以永久提升移动速度 25%。 |
