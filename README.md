# 潮汐之间 · 海岛探索

一个单页、原生 HTML/CSS/JavaScript 的俯视角海岛探索游戏。地图与角色由 Canvas 程序化绘制，无第三方运行时依赖。

## 玩法

在三处区域间航行、采集浮木、旧贝壳与潮光，协助雾灯港修复灯塔。修复需要 **3 根浮木和 2 枚旧贝壳**。灯塔点亮后，选择公开安全航路或交给海商公会：前者让岛民获得通行权并得到 2 枚旧贝壳；后者让贸易增长但航路受公会管制，并得到 2 根浮木和 1 枚潮光。两种结局都可继续探索。

| 区域 | 势力 / 人物 | 任务 |
| --- | --- | --- |
| 雾灯港 | 港务自治会；灯塔守望者梅 | 收集材料修复灯塔，并决定安全航路的归属。 |
| 红脊雨林岛 | 巡林团；红脊矿业营地 | 收集污染水样并提交给巡林团。 |
| 沉船礁 | 漂泊者聚落 | 取回导航核心，选择归还或强化装备。 |

## 控制

- 桌面：`W A S D` 或方向键移动；`E` 互动；点击底部区域按钮切换岛屿。
- 触屏：使用画面左下方向键移动，按“互动”收集或与人物交谈；点击底部区域按钮航行。

## 设置、更新与存档

在游戏顶部点击 **⚙ 设置**，查看当前版本并选择 **检查更新**。发现新版后点击 **应用更新**，确认后游戏会使用最新部署版本覆盖旧版并重新加载。

游戏进度会自动保存在当前浏览器/设备中，更新、重载或重新打开页面后会恢复；不同设备或浏览器配置文件之间不自动同步。清除浏览器站点数据会删除本地存档。

**首次升级说明：** 早期线上版本没有内置更新器，因此部署本版本后，已打开的旧标签页需手动刷新一次以载入更新器。此后可直接在游戏设置中检查并应用后续版本。

## 发布文件

- `island_explorer/index.html`：游戏页面、样式与程序脚本。
- `island_explorer/update.json`：页面读取的同源版本清单与更新说明。
- `README.md`：项目文档，不属于网页部署目录。

发布新版本时，保持 `index.html` 中的 `APP_VERSION` 与 `update.json` 中的 `version` 一致，并只部署游戏目录内容。版本清单使用无缓存请求，应用更新时会带版本号和时间戳重新载入页面。
